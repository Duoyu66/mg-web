## 概览

掌握 REST 设计、版本与错误模型，能定义清晰、可演进的接口。

## 核心知识

- REST 基础：资源建模、HTTP 方法与状态码、幂等与分页
- 工程化：统一错误码、接口文档与 Mock、OpenAPI/SDK 生成

## 学习清单

- 能设计列表/详情/搜索接口
- 能统一错误返回
- 能写 OpenAPI 并生成类型

## 推荐资源

- HTTP Semantics (RFC 9110) — https://www.rfc-editor.org/rfc/rfc9110
- OpenAPI — https://www.openapis.org/
