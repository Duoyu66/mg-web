## 概览

通过容器化与流水线提升交付效率，形成可重复、可回滚的发布体系。

## 核心知识

- 容器化：Dockerfile、镜像分层、安全与体积优化
- 交付：CI/CD 流水线、灰度/回滚、环境隔离

## 学习清单

- 能写出可用 Dockerfile
- 能搭建基础 CI/CD
- 能做回滚与发布策略

- Kubernetes Docs — https://kubernetes.io/docs/
