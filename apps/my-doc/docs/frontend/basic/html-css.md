## 概览

掌握语义化结构、布局与响应式，能独立还原常见页面。

## 为什么学

- 所有前端能力都建立在结构与样式之上
- 面试高频：BFC、Flex/Grid、响应式、层叠与优先级

## 核心知识

- HTML 基础：语义化标签、表单与可访问性、SEO 基础
- CSS 核心：盒模型与层叠、Flex/Grid 布局、响应式与媒体查询

## 学习清单

- 能还原 3 个中等复杂度页面
- 能写出 Flex/Grid 两套布局
- 能处理移动端适配
